S-Paxel OS — это реальная операционная система, написанная с нуля 
на C и ассемблере. Работает в 32-битном защищённом режиме без libc, 
без Linux и без готовых фреймворков.

Система загружается через Multiboot (GRUB), имеет собственное ядро, 
VGA-драйвер, драйвер клавиатуры PS/2, виртуальную файловую систему 
и графическую оболочку с рабочим столом (текстовый режим).

ОС протестирована и работает на:
  • VirtualBox
  • Реальном железе (Dell Latitude E6420, 2011 г.)

Возможности:
  • Рабочий стол с иконками (WASD/стрелки — навигация)
  • Терминал с командами (ls, cd, open, cat, mkdir, rm, mem, hardware)
  • 3 игры: Snake, Parity X, Numbers X
  • Приложения: Notes (блокнот), Editor (редактор), Files (проводник), 
    Calc (калькулятор), Info (о системе)
  • Power Menu: перезагрузка, выключение (в эмуляторах)
  • Определение CPU через CPUID (Intel Core i5-3340M и др.)
  • Определение RAM через Multiboot (до 6+ ГБ)
  • Часы uptime на рабочем столе
  • Виртуальная ФС с папками и файлами
  • Сохранение файлов в /saved/

Технические характеристики:
  • Архитектура: x86, 32-бит (protected mode)
  • Загрузка: Multiboot (GRUB)
  • Размер ядра: ~41 КБ
  • RAM: работает даже на 4 МБ (реально использует ~60 КБ)
  • Компилятор: gcc -m32 (freestanding)
  • Сборка: bash build.sh

Проект создан ради удовольствия и изучения низкоуровневого 
программирования. Код открыт на GitHub — можно изучать, копировать, модифицировать, использовать как учебный материал.
